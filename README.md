# 🌾 AgriShield – AI-Powered Farmer Disaster Early Warning System

## Overview

AgriShield is an AI-powered web application designed to help farmers prepare for climate-related disasters such as floods, heatwaves, droughts, and storms. The system uses real-time weather data to assess potential risks and provide actionable recommendations for crop protection.

This project aims to improve climate resilience in agriculture by enabling farmers to make informed decisions before adverse weather conditions impact their crops.

---

## Problem Statement

Farmers often suffer significant crop losses due to unexpected weather events such as:

* Floods
* Heatwaves
* Storms
* Extreme humidity

Many small-scale farmers lack access to timely warnings and decision-support tools.

---

## Solution

AgriShield analyzes real-time weather conditions and evaluates disaster risks based on the selected crop and environmental conditions. It then provides early warnings and recommendations to help farmers reduce potential losses.

---

## Key Features

* Real-time weather monitoring
* Temperature, humidity, and wind speed analysis
* Flood risk assessment
* Heatwave risk assessment
* Storm risk assessment
* Crop damage risk prediction
* Farmer-friendly dashboard
* Climate resilience recommendations

## How It Works

1. Farmer enters location.
2. Farmer selects crop type.
3. System fetches live weather data.
4. Risk analysis is performed.
5. Disaster warnings are generated.
6. Recommendations are displayed.
